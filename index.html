Karousel Ticker Demo

A Simple Image/Logo Carousel mostly used for logo tickers. This carousel is implemented using plain JavaScript and does not require any jQuery library.

Features

  • Lightweight and fast
  • No dependencies on external libraries
  • Easy to integrate and customize
  • Responsive design
  • Supports infinite looping
  • Smooth transition effects
  • Configurable autoplay settings (direction, speed)
  • Draggable with momentum, auto-scroll resumes in the dragged direction
  • "Entangled" carousels: link any number of tickers, anywhere on the page, to drag together
  • Pause on hover, per-ticker or synced across the whole page
  • Lays out full-viewport-width automatically, with or without Bootstrap
  • Cross-browser compatibility

See the README for the full list of options.

Multiple Karousel

Both rows below share data-karousel-group="multiple-demo", so they're entangled: drag either one and both move together, in lockstep, release on one and both pick up the same momentum and continuing direction. Carousels are only linked this way if they explicitly share a group value — everything else on this page drags independently. There's a third carousel using this exact same group much further down the page (see "Far-Away Entangled Karousel" near the bottom) — entangled carousels don't need to be adjacent, or even in the same section.

Direction

data-direction sets which way the ticker auto-scrolls: right-to-left (the default) or left-to-right. Drag either one — it'll flip to auto-scroll in whichever direction you just dragged it.

Pause on Hover

data-pause-on-hover="true" pauses the ticker while the mouse is over it. data-sync-pause decides whether that pause is felt by every ticker on the page (true, the default) or only this one (false). Hover the first row below — only it pauses, the second row keeps scrolling.

Clickable Content Inside an Item

A .karousel-item can be, or contain, a real link or button — it's not limited to plain text/images. The first card below is itself an <a>, with the href covering the whole card, which is normally the scenario that breaks a drag (the browser tries to start its own native link-drag the instant you press down on it). Dragging the track still works here, and a genuine click still navigates — only an actual drag is suppressed as a click.

How to Use

Include js/KarouselTicker.js — that's the only required file, since it injects the .karousel-container/.karousel-track styles the slider itself needs. Then create a container with the class karousel-container and add your items inside a karousel-track div: 

<div class="karousel-container" data-direction="right-to-left" data-speed="1">
    <div class="karousel-track">
        <div class="karousel-item">Logo 1</div>
        <div class="karousel-item">Logo 2</div>
    </div>
</div>

<script src="js/KarouselTicker.js"></script>
<script>
    window.addEventListener('load', () => {
        document.querySelectorAll('.karousel-container').forEach(el => new KarouselTicker(el));
    });
</script>

Every setting — direction, speed, pause-on-hover, draggability, and entanglement group — is read from data-* attributes on the .karousel-container element, as demonstrated in each example above. See the README for the full attribute reference.

.karousel-item's base layout (flex-shrink, box-sizing, spacing, list-style) is applied by the script too — the only thing left to CSS is presentation you want to add yourself (size, border, background, an img inside it, etc). css/style.css in this repo is just one example of that. Links and buttons inside a .karousel-item are fully clickable — dragging is only distinguished from a tap by pointer distance, not by disabling clicks.
