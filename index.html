Draggable, with momentum

Grab it, flick it, let go — it eases out naturally instead of stopping dead.

⟲

Direction-aware resume

After a drag, auto-scroll continues in whichever direction you just dragged it — not whatever it started with.

⚛

Entangled carousels

Link any number of tickers, anywhere on the page, so dragging one drags all of them — in lockstep.

⏸

Smart pause on hover

Pause a single ticker, or sync the pause across every ticker on the page — your call.

▭

Self-contained layout

The script applies its own required styles at runtime — no stylesheet needed, and it stretches full-bleed even nested inside a constrained container.

Quick start

Drop it in

Only js/KarouselTicker.js is required — it applies every style the slider mechanism itself needs directly to the elements at runtime, so there's no external stylesheet to remember.

<div class="karousel-container" data-direction="right-to-left" data-speed="1">
    <div class="karousel-track">
        <div class="karousel-item">Logo 1</div>
        <div class="karousel-item">Logo 2</div>
    </div>
</div>

<script src="js/KarouselTicker.js"></script>
<script>
    window.addEventListener('load', () => {
        document.querySelectorAll('.karousel-container').forEach(el => new KarouselTicker(el));
    });
</script>

Every setting on this page — direction, speed, pause-on-hover, draggability, entanglement group — is read straight from data-* attributes on the .karousel-container element. No JS configuration object needed.

.karousel-item is yours to style however you like (size, border, background, an img inside it) — css/style.css in this repo is just one example. Its base layout (flex-shrink, box-sizing, spacing) is applied by the script too, so it lays out correctly even with no CSS at all.

Reference

Every data-* option

Attribute Values Default Description
data-direction right-to-left | left-to-right right-to-left Which way the ticker auto-scrolls. Flips automatically after a drag to match whichever direction you last dragged.
data-speed number (px per frame) 1 Auto-scroll speed. Higher is faster.
data-pause-on-hover true | false false Pause the auto-scroll while the mouse is over the container.
data-sync-pause true | false true Only matters with pause-on-hover enabled. true pauses every ticker on the page; false pauses only that one.
data-draggable true | false true Whether the user can drag/swipe the track, with momentum on release.
data-karousel-group any string (none) Carousels sharing the same value are "entangled": dragging one drags every other one in the group, anywhere on the page.

See the README for the full write-up, including entangled carousels and the full-bleed layout behavior.
